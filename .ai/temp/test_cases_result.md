### 阻塞项（3 项）

| ID | 描述 | 严重程度 | 修复建议 |
|----|------|----------|----------|
| BUG-V26-01 | 采纳检测只执行一次，无法实现 3/7/14/30 天多次检测 | 高 | 修改去重逻辑，按 days_after_publish 区分多次检测 |
| BUG-V26-02 | 配额检查在生成之后执行，用户可绕过配额 | 高 | 在 POST /generate 端点添加 require_quota("content") |
| BUG-V26-03 | 平台收录检测直接抓取 Google，违反 ToS | 高 | 改用 Google Search API 或第三方 SEO API |

### 建议项（12 项）

| ID | 描述 | 严重程度 | 修复建议 |
|----|------|----------|----------|
| BUG-V26-04 | query/check 维度配额硬编码为无限 | 中 | 从 subscription_plans 表读取实际限制 |
| BUG-V26-05 | AdoptionCheck 创建时未设置 days_after_publish | 中 | 计算并设置该字段 |
| BUG-V26-06 | publish 端点允许重复发布 | 中 | 检查状态，已 published 则返回 400 |
| BUG-V26-07 | regenerate_section 是同步阻塞调用 | 中 | 改为异步任务（与 generate 一致） |
| BUG-V26-08 | _generation_locks 字典无限增长 | 低 | 添加 TTL 或 LRU 淘汰机制 |
| BUG-V26-09 | 两套编辑器体系并存，图片上传方式不统一 | 中 | 统一使用 TipTapEditor + ImageUploadDialog |
| BUG-V26-10 | 订阅页面 billing_cycle 硬编码为 monthly | 中 | 添加月付/年付切换选项 |
| BUG-V26-11 | 采纳数据展示三处不一致 | 低 | 统一使用 AdoptionTimeline 组件 |
| BUG-V26-12 | 错误处理模式不统一 | 低 | 统一使用 setError + UI 展示 |
