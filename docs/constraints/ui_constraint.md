# UI 约束

## 品牌色
- 主色（Primary）：#409EFF（蓝色）
- 辅助色（Secondary）：#67C23A（绿色）
- 强调色（Accent）：#E6A23C（橙色）
- 危险色（Danger）：#F56C6C（红色）
- 背景色（Background）：#F5F7FA
- 文字色（Text Primary）：#303133
- 文字色（Text Secondary）：#909399

## 风格调性
- 商务简洁：白底 + 浅灰分区 + 蓝色主调
- 信息密度适中：卡片式布局，留白 ≥16px
- 企业级 B2B：数据表格为主，表单次之

## UI 组件库
- Tailwind CSS 3（原子化样式框架）
- Chart.js + react-chartjs-2（图表）
- react-icons（图标库）
- Headless UI / Radix（如需复杂交互组件）

## 响应式断点
- Desktop：≥1200px（主布局）
- Tablet：768px – 1199px
- Mobile：<768px（MVP 阶段不优先适配）

## 字体
- 中文：PingFang SC / Microsoft YaHei
- 英文/数字：Inter / Roboto Mono
- 代码：JetBrains Mono / Fira Code
- 字号基准：14px（正文），12px（辅助），16px（标题）

## 间距系统
- 基准单位：4px
- 常用间距：8 / 12 / 16 / 24 / 32 / 48px
- 组件内边距：16px
- 卡片间距：16px / 24px

## 圆角
- 小组件（按钮、输入框）：4px
- 卡片/面板：8px
- 对话框：12px

## 阴影
- 卡片：0 2px 12px rgba(0,0,0,0.08)
- 下拉/弹出：0 4px 16px rgba(0,0,0,0.12)
- 悬浮提升：0 8px 24px rgba(0,0,0,0.16)
