## 9. 部署变更

### 9.1 新增依赖

```bash
# 后端
pip install celery>=5.3.0 jieba>=0.42.1

# 前端
npm install @tanstack/react-virtual  # 虚拟滚动（待集成）
```

### 9.2 环境变量

```bash
# 新增
SERP_API_KEY=your_serp_api_key
SERP_API_PROVIDER=serpapi  # 或 valueserp
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your-email@gmail.com
SMTP_PASSWORD=your-app-password
```

### 9.3 Docker Compose 变更

```yaml
# 新增 Celery worker
celery-worker:
  build: ./backend
  command: celery -A celery_app worker --loglevel=info
  depends_on:
    - redis
    - db

# 新增 Celery beat
celery-beat:
  build: ./backend
  command: celery -A celery_app beat --loglevel=info
  depends_on:
    - redis
```
